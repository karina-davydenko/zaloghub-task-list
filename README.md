# zaloghub-task-list

Тестовое задание ZalogHub: список задач на React, TypeScript и Vite.

## Возможности

- Добавление задачи кнопкой или через Enter. Пробелы по краям удаляются, пустой ввод отклоняется.
- Переключение выполнения и удаление задачи.
- Фильтры: все, активные, выполненные.
- Сохранение задач после перезагрузки через localStorage.
- Проверка сохранённых данных и предупреждения при ошибках хранения.
- Адаптивный интерфейс на русском, доступные названия элементов и видимый фокус клавиатуры.

## Запуск

Требуется Node.js 22.12+ в ветке 22 LTS либо Node.js 24+ и npm. Финальные проверки выполнены на Node.js 22.23.3.

```bash
git clone https://github.com/karina-davydenko/zaloghub-task-list.git
cd zaloghub-task-list
npm ci
npm run dev
```

Откройте адрес, показанный в терминале.

## Проверки и сборка

```bash
npm run lint
npm test
npm run build
npm run preview
```

`lint` запускает Oxlint. Тесты используют Vitest, React Testing Library и jsdom. `build` проверяет TypeScript и создаёт production-сборку в `dist`. `preview` запускает локальный просмотр сборки.

Тестами покрыты добавление и пустой ввод, переключение выполнения, фильтрация, удаление, восстановление в StrictMode, сохранение пустого списка, повреждённые данные и ошибки localStorage.

## Основные решения и ограничения

Состояние задач и выбранный фильтр хранятся в `App`. Отображаемый список вычисляется из общего массива. Форма, фильтры и строка задачи выделены в отдельные компоненты. Для идентификаторов используется `crypto.randomUUID()`.

Данные загружаются при инициализации состояния. Модуль `storage.ts` проверяет JSON и структуру задач, включая уникальность ID. Запись выполняется только при изменениях пользователя, поэтому запуск приложения не перезаписывает сохранённые данные. Если запись недоступна, приложение продолжает работать в памяти и показывает предупреждение.

Сервера и API нет. Данные доступны только в текущем браузере и для текущего адреса приложения. Очистка данных браузера удаляет список. При повреждённых данных открывается пустой список с предупреждением; следующее изменение заменяет сохранённые данные. Синхронизация между вкладками и устройствами не предусмотрена. Нужен современный браузер с поддержкой `crypto.randomUUID()`; для запуска используйте localhost или HTTPS.

## Ручная проверка

- Добавление кнопкой и Enter; пустой ввод и пробелы.
- Переключение выполнения; все три фильтра.
- Удаление при выбранном фильтре.
- Перезагрузка с задачами и после удаления всех задач.
- Повреждённые данные localStorage.
- Узкий экран, длинные названия и управление клавиатурой.

Для проверки повреждённых данных на локальном приложении выполните в консоли браузера и перезагрузите страницу:

```js
localStorage.setItem('zaloghub-tasks', '{')
```

Эта проверка заменяет сохранённый список; используйте тестовые задачи.
