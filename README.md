# zaloghub-task-list

Тестовое задание ZalogHub: список задач на React, TypeScript и Vite.

## Запуск

Требуется Node.js 22.12+ и npm. Проверки текущего этапа выполняются на Node.js 23.0.0 и npm 10.9.0.

```bash
npm ci
npm run dev
```

## Проверки и сборка

```bash
npm run lint
npm run build
npm run preview
```

`build` проверяет TypeScript и создаёт production-сборку в `dist`. `preview` позволяет открыть её локально.
